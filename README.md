## 🚀 Featured Projects

### 🌡️ **CpuTemp** - CPU Governor Controller
Advanced performance optimization for Android with Root access. Control CPU frequencies in real-time with three power profiles (Boost, Normal, Cool). Integrates seamlessly with Magisk and KernelSU.

**Stack:** `Kotlin` | **License:** `MIT`  
📍 [Repository](https://github.com/Jaypsmall/CpuTemp)

---

### 😈 **DemoniTalk** - Voice Automation Engine
Intelligent voice assistant with advanced automation capabilities. Map custom voice triggers to execute complex system macros, scripts, and automations. Features interactive overlay and continuous/manual listening modes.

**Stack:** `Kotlin` | **License:** `MIT`  
📍 [Repository](https://github.com/Jaypsmall/DemoniTalk)

---

### 🎨 **DemoniDraw** - Gesture-Based Automation
Innovative gesture recognition engine for Android. Draw patterns on screen to trigger complex macros, system commands, and automated workflows. Optimized for low latency and minimal battery impact.

**Stack:** `Kotlin` | **License:** `MIT`  
📍 [Repository](https://github.com/Jaypsmall/DemoniDraw)

---

### 🎙️ **ProVoiceChanger** - Real-Time Audio Effects
Native Android voice changer with real-time processing. Transform audio with pitch, distortion, and chunk controls. Designed for Huawei devices with local, low-latency processing.

**Stack:** `Java` | **License:** `MIT`  
📍 [Repository](https://github.com/Jaypsmall/ProVoiceChanger)

---

### 🔓 **HexRootScan** - Network Auditing & Pentest Tool
Powerful penetration testing suite for Android featuring integrated Nmap, Whois, DNS analysis, Nikto vulnerability scanning, and Shodan integration. Dark, optimized UI for advanced network reconnaissance.

**Stack:** `Kotlin` | **License:** `MIT`  
📍 [Repository](https://github.com/Jaypsmall/HexRootScan)
